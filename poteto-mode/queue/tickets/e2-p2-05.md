## Implementation steps

1. Add domain-local structural input types mirroring CloseConsultaRequest fields needed for invariants (no `@genki/shared` runtime import).

2. Implement `validateConsulta(input, nowIso)` throwing `new ClinicalError('invalid_bundle', …)` when:
   - diagnoses empty, or principal count ≠ 1;
   - any `diagnostico_index` out of range `[0, diagnosticos.length)`;
   - any diagnosis lacks ≥1 treatment;
   - `fecha_hora_inicio` is later than `nowIso`;
   - any treatment `fecha_fin_estimada` present and earlier than `fecha_inicio`;
   - `receta` present with empty detalles, or duplicate `id_medicamento` among detalles.

3. Accept a valid minimal bundle (with and without recipe) without throwing. Do not check medication catalog presence/active state here.

4. Leave HTTP Zod schemas, ports, adapters, application use cases, and Auth/JWT untouched.
