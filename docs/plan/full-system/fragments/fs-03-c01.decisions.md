Local adoption notes. Central `DECISIONS.md` holds ADR FS-001..014; wire folds later evidence.

| Decision | Why | Rejected |
| --- | --- | --- |
| `PatientRepositoryPort.op09/op10` + `executeOp09/10` orchestration | Exact F1 naming; application owns role/schema checks then UoW | Fine-grained get/update/list port methods that fork F1 |
| Pure domain parsers for patch/contacto + role allowlists | Boundary validation; keep adapter persistence-only | Zod-only in adapter; scattering role checks in memory map code |
| Contacts in `extensions.patient.contactos` on shared memory snapshot | Foundation extension map; same UoW rollback as pacientes | Separate MemoryInstitutionState / second mutex |
| `failAfterWrite(0)` → `store_unavailable`; `n>0` → `internal_error` after n writes | Matches F4 store vs mid-write rows without extra harness API | Editing foundation FullHarness / package pregate |
| Duplicate contact identity → `conflict` | Named OP-10 domain error; leaves state unchanged | Treating principal replace itself as conflict (source requires atomic replace) |
| Shared `IdPort` across `otherInstitution()` harness | Foreign id must not collide with local patient id in memory fixtures | Per-institution sequences that make foreign lookups accidentally succeed |
