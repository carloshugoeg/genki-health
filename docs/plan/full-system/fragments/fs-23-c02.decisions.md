# FS-23-C02 decisions

## D1 — Extend C01 ChargesPersistence with disposition + tariff reads

- **Decision:** Keep `executeOpNN` → `context.modules.charges.opNN` and grow `ChargesPersistence` with `findCargo`, `updateCargoDisposicion`, `listServicios`, and `hasInstitution`. Domain owns disposition schema/role/transition and public-tariff projection.
- **Why:** Same F1 shape as C01; billing rules stay out of the memory adapter; depcruise stays clean.
- **Rejected:** Fat adapter owning disposition/tariff rules; new port file; editing foundation `context.ts`.
- **ADR links:** FS-008 (money/idempotency), FS-012 (module fragment ownership), FS-014 (invoiced cargo uniqueness).

## D2 — Disposition requires caja + `cargo.autorizar`; facturado is conflict

- **Decision:** Role gate is `roles` includes `caja` and `permissions` includes `cargo.autorizar`. Only `pendiente` → `anulado`|`cortesia`. `facturado` (and any non-pendiente) throws `conflict`. Audit reason stored as extension `motivo_disposicion` on `CargoStored`, not on frozen `CARGO` TS interface.
- **Why:** SECURITY-FREE and F2 require explicit permission; schema-additions.json adds `motivo_disposicion`; foundation `schema.ts` stays untouched.
- **Rejected:** Treating caja role alone as enough; mutating foundation CARGO fields; deleting cargos.

## D3 — Tarifario is institution-bound vigente page; foreign uses store home binding

- **Decision:** OP71 returns vigente services for the actor institution, excludes `tipo === 'honorario'`, empty list is 200. `hasInstitution` is the memory store's `homeInstitutionId`; a foreign actor institution on another store binding yields `not_found` without inventing a parent route id.
- **Why:** F4 forbids inventing 404 for empty catalogs; projection-isolation fixture covers foreign for parentless reads.
- **Rejected:** 404 on empty tariff; including inactive or honorario rows; adding package `pregate` in this PR.
